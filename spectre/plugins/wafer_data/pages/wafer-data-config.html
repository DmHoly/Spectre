Fiche data des plaques

Ce que montre l'onglet « Data » de chaque plaque d'un projet corporate : ses données principales, lues dans PRISM et gardées résumées. Une valeur se situe parmi les plaques du projet déjà calculées.

Vous pouvez lire cette fiche, pas la modifier (administrateur ou manager d'une équipe du projet).

Calculer les fiches du projet

Une fiche se calcule à sa première ouverture. La calculer d'avance pour toutes les plaques du projet situe chaque valeur parmi toutes les autres - et rend l'onglet immédiat. Seules les fiches qui manquent sont calculées.
