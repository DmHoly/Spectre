Refs

Les points de départ réutilisables de ce µprojet : chaque nouvelle piste part généralement d'une ref plutôt que de repartir de zéro. Une ref garde le même nom (un surnom, ou par défaut « ref vX.Y.Z ») quel que soit le nombre de fois où on en dérive.

Aucune ref pour l'instant. Ouvrez une expérience et utilisez « Faire de cette version une ref » pour en créer une.
